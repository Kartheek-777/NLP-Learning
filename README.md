# NLP Learning 📝

This repository contains my learning and practice of Natural Language Processing (NLP) using Python.

I am learning NLP step by step, starting with basic text processing and moving towards advanced NLP concepts and real-world applications.

## 📚 Topics

### 01 - NLP Basics
- Text Processing
- Tokenization
- Stopwords
- Stemming
- Lemmatization
- Basic NLP Practice

### 02 - Text Preprocessing
- Text Cleaning
- Removing Special Characters
- Removing Numbers
- Lowercase Conversion
- Regular Expressions
- Handling Missing Text
- Normalization

### 03 - Feature Extraction
- Bag of Words
- TF-IDF
- N-Grams
- Count Vectorizer
- Tfidf Vectorizer

### 04 - Text Classification
- Text Classification Basics
- Naive Bayes
- Logistic Regression
- Support Vector Machine
- Model Evaluation

### 05 - Sentiment Analysis
- Positive and Negative Sentiment
- Sentiment Classification
- Text Classification for Sentiment
- Sentiment Analysis Projects

### 06 - Advanced NLP
- Word Embeddings
- Word2Vec
- Named Entity Recognition
- Part-of-Speech Tagging
- Transformers
- Hugging Face
- Large Language Models
